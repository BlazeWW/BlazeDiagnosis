# BD-056 — Contextual help and onboarding

**GitHub issue:** [#148](https://github.com/BlazeWW/BlazeDiagnosis/issues/148)  
**Squad:** UX and Accessibility  
**Status:** implementation candidate added to the supplied source snapshot; local quality gates and independent review remain required.

## Baseline observed in the supplied source

- The customer dashboard renders a customer form, customer directory and dashboard statistics. Its page description explicitly identifies the panels as client-side until customer server actions are connected.
- The station dashboard renders station dashboard sections inside a loading boundary and a station production checklist.
- Neither supplied dashboard page previously rendered an onboarding guide or contextual help component.
- `FormField` already associates field labels, descriptions and validation errors with controls using `htmlFor`, `aria-describedby` and `aria-invalid`.
- The live GitHub issue is open and asks for in-product hints and first-run walkthroughs, including dismissal, redisplay and small-screen verification.

## Implementation included

- A reusable client-side onboarding guide is rendered in the customer and station dashboards.
- First-run visibility and dismissal are stored separately per portal in browser local storage.
- The guide can be dismissed and reopened without navigating away from the dashboard.
- Contextual hints are rendered alongside the customer workspace and station dashboard.
- Guide cards use responsive single-column/mobile and three-column/desktop layouts; controls have accessible names and visible text labels.
- Guidance links point only to routes already present in the supplied application tree. This UI does not add APIs, database fields, tenant identity, or permission changes.

## Automated tests

- `src/components/onboarding/onboardingPreferences.test.ts`: per-portal preference isolation, dismissal/redisplay and unavailable-storage handling.
- `src/components/onboarding/contextualHelp.test.tsx`: contextual help accessible label and content rendering.

## Manual interaction verification still required

1. Clear site storage and open `/en/customer`; confirm the guide appears.
2. Dismiss the guide; confirm the customer workspace remains usable and form values are not reset.
3. Select **Show getting started guide**; confirm the guide reappears.
4. Repeat on `/en/station`; confirm customer and station dismissal states are independent.
5. Repeat at a narrow mobile viewport; confirm cards stack and all controls remain reachable by keyboard.
6. Confirm the guide links navigate to the intended customer and station pages.
