## Implementation sequence

1. Identify quote PDF data and brand tokens while excluding internal supplier margin and notes.
2. Build deterministic branded document output from approved DTOs.
3. Verify page breaks, number/total formatting, customer identification and long text handling.
4. Include downloadable/printable test artefacts with no real customer data.
